# Command panel V1 archive

Frozen source snapshots of the target-first command workspace before V2 (2026-10-22).
The runnable compatibility entry is `src/components/HUD/UnifiedCommandPanelLegacy.tsx`.
Choose Legacy in V2 to restore both original command and target columns. Choose Try Commands V2 to return.
The preference persists in `mume-command-panel-version`; 1 selects V1 and 2 selects V2. New sessions default to V2.
Shared hooks remain live so protocol, capture and gameplay fixes apply to both versions.
