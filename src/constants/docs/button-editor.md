# Button Editor

Tactical custom buttons keep your hands free during high-stakes combat.

## 🔧 Editing Buttons
- **Design Mode:** Toggle "Enter Design Mode" from the main menu (top-right cog).
- **Edit Details:** Tap any action button to set its primary command, label, color, and icon.
- **Swipe Wheels:** Each button can bind up to 4 swipe directions. Swipe to execute separate actions.

## 💡 Pro Tips
- **Variables:** Use `%t` in button commands to insert your active target's name automatically.
- **Silent Commands:** Toggle "Silent" on a button to run the command without echoing it in your log.
