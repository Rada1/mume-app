# Mapping Tips

Navigate the wilderness of Arda with ease.

## 🗺️ Map Sync
- **Get Sync:** If the map doesn't match your game location, type `/sync` or right-click (long-press on mobile) a room and select "Set Sync".
- **Peek Mode:** Adjacent unexplored rooms are partially visible so you can plan your route.

## 📥 Import Map
- **Import:** Open Map Settings from the menu to upload standard `.mm2` files from MMapper.
