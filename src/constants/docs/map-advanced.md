# Advanced Mapping

The MUME client features a powerful, automated mapping system.

## 🧭 Smart Navigation
- **Hold to Walk**: Long-press any room on the map to automatically walk there. The character will take the shortest path.
- **Sequential Movement**: Commands are sent one-by-one only after the client confirms you have changed rooms.
- **Release to Stop**: Simply lift your finger or mouse button at any time to stop movement safely.
- **Keyboard Navigation**: In desktop mode, use arrow keys or WASD for tactile movement.

## 🔍 Visual Indicators
- **Dynamic Exploration**: Your map comes to life as you explore. New rooms fade in over 800ms, and the "Fog of War" gradually lifts.
- **Peek Effect**: Adjacent unexplored rooms are semi-visible, giving you a hint of what lies ahead without spoiling the discovery.
- **Interactive Layers**: The mapper supports multiple layers (Grid, Terrain, Icons).
- **Vertical Exits**: Small arrows (▲/▼) indicate if a room has an up or down exit.

## 🏗️ Design Mode
Enable "Design Mode" in the main menu to manually edit the map:
- **Set Sync**: Use the context menu to force-sync your location to a specific coordinate if you get lost.
- **Legend**:
    - `?`: Quest or Point of Interest
    - `!`: Aggressive NPCS or Hazard
    - `▲/▼`: Vertical Transitions

## 📥 External Data
The client supports `.mm2` files from MMapper. Use the mapper settings to import your existing world data for immediate navigation across Middle-earth.
